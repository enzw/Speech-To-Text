Buatkan saya sebuah **server Speech-to-Text (STT) menggunakan Whisper** yang akan digunakan sebagai backend untuk perangkat IoT berbasis **Wemos D1 Mini (ESP8266)**.

### Tujuan sistem

Alur sistem yang saya inginkan:

**Wemos D1 Mini + microphone → WiFi → HTTP POST → Server Whisper → hasil transkripsi teks → Wemos**

Wemos tidak menjalankan Whisper secara lokal. Semua proses speech-to-text dilakukan di server.

### Requirements utama

Gunakan:

* **Python 3**
* **FastAPI** untuk REST API
* **Whisper** untuk speech-to-text
* **FFmpeg** untuk decoding audio
* Server harus bisa dijalankan di **Replit**
* API harus sederhana dan ringan agar mudah dipanggil oleh ESP8266

### Endpoint

Buat endpoint:

`POST /transcribe`

Endpoint menerima file audio melalui `multipart/form-data`.

Contoh request:

```http
POST /transcribe
Content-Type: multipart/form-data
file: audio.wav
```

Response JSON:

```json
{
  "success": true,
  "text": "halo bagaimana kabarmu"
}
```

Jika terjadi error:

```json
{
  "success": false,
  "error": "deskripsi error"
}
```

### Format audio

Server harus mendukung minimal:

* WAV
* MP3
* M4A
* OGG
* WebM

Karena client saya adalah ESP8266, prioritaskan **WAV PCM** sebagai format utama.

Server harus dapat menangani audio:

* Mono
* 16-bit PCM
* Sample rate 16000 Hz

Jika memungkinkan, lakukan preprocessing/conversion menggunakan FFmpeg sebelum dikirim ke Whisper agar audio selalu menjadi:

```text
mono
16000 Hz
16-bit PCM WAV
```

### Whisper

Gunakan Whisper dengan model yang ringan agar server Replit tidak terlalu berat.

Prioritaskan:

```text
tiny
```

atau:

```text
base
```

Buat model dapat dikonfigurasi melalui environment variable:

```env
WHISPER_MODEL=tiny
```

Jangan load model setiap kali endpoint dipanggil.

Model Whisper harus **diload sekali ketika server startup**, kemudian digunakan untuk request berikutnya.

### Bahasa

Prioritaskan Bahasa Indonesia.

Gunakan konfigurasi Whisper yang sesuai, misalnya:

```python
language="id"
```

Namun tetap buat environment variable:

```env
WHISPER_LANGUAGE=id
```

Jika language tidak diisi, Whisper boleh melakukan language detection otomatis.

### Keamanan

Tambahkan API key sederhana.

Environment variable:

```env
API_KEY=your-secret-key
```

Client harus mengirim:

```http
X-API-Key: your-secret-key
```

Jika API key salah, return:

```http
401 Unauthorized
```

### File handling

Jangan menyimpan file audio secara permanen.

Flow:

1. Terima upload
2. Simpan sementara
3. Convert/preprocess
4. Transcribe menggunakan Whisper
5. Hapus file temporary
6. Return hasil JSON

Pastikan file temporary tetap dihapus walaupun terjadi error.

Tambahkan batas ukuran file, misalnya maksimal **10 MB**.

### Replit

Buat project agar langsung bisa dijalankan di Replit.

Server harus listen pada:

```text
0.0.0.0
```

dan port dari environment variable:

```python
PORT
```

Gunakan:

```python
uvicorn main:app --host 0.0.0.0 --port $PORT
```

Sesuaikan konfigurasi Replit jika diperlukan.

### Error handling

Tangani error untuk:

* file tidak dikirim
* format audio tidak valid
* file terlalu besar
* FFmpeg gagal
* Whisper gagal
* API key salah
* server error

Response harus selalu JSON yang jelas.
